# Eatoday · 今天吃什么

> 中午别再跟自己拉扯了。按住一个键，让轮盘替你决定。

**Eatoday** 把 FoloToy AI Passport 变成一台口袋里的“今天吃哪家”轮盘。内置 30 家北京
馆子和品类，三个实体按键负责转，自己加的条目会带着星标一起进轮盘。不联网、不开蓝牙、
不用账号、不连手机——开机就能玩。

**版本：v0.1**

## 怎么玩

| 场景 | 手势 | 结果 |
| --- | --- | --- |
| 主界面 | 长按 `上` | 轮盘开始转；松手后减速停住 |
| 主界面 | 短按 `下` | 手动切到下一个 |
| 主界面 | 长按 `下` | 在“全部”和“仅种子池”之间切换轮盘范围 |
| 主界面 | 短按 `确定` | 认下眼前这个结果 |
| 主界面 | 长按 `确定` | 打开添加页 |
| 旋转中 | 松开 `上` | 开始减速 |
| 旋转中 | 短按 `下` | 立刻停在当前项 |
| 添加页 | 短按 `上` / `下` | 在候选词之间移动 |
| 添加页 | 短按 `确定` | 选中该词作为品类，再按一次可追加一个短名称 |
| 添加页 | 长按 `确定` | 存进自己的列表 |
| 添加页 | 长按 `上` | 取消并返回 |

中央卡片用大字显示当前选项，下面一行是“种子池 N · 我的 M”，再下面一行显示轮盘范围。
自己加的条目会带 ★ 前缀。

## 里面有什么

- **30 项种子池**：京菜烤鸭、小吃快餐、火锅、川味、家常、亲民小馆，再加一组“懒得想”
  的兜底选择。
- **自己的列表**：存在设备上，不用安装、不用同步。
- **种子池写进 Flash**：首次启动写入 NVS，之后从 NVS 读回；副本损坏时回落到内置表。
- **12 个候选词**：添加页用选择代替打字，三个键也能输入。

## 编译与刷写

需要 ESP-IDF 5.5.3（esp32c3）。合并镜像可直接写到 `0x0`：

```bash
./tools/validate.sh            # 仓库检查 + 主机测试 + 固件构建
python -m esptool --chip esp32c3 -p <PORT> write_flash 0x0 build/FoloToy-AI-Passport-full.bin
```

主机测试覆盖停止后的索引计算、用户列表、按键路由状态机和字体逐字覆盖，
不接硬件也能验证逻辑。
