# Eatoday · 今天吃什么

> 中午别再跟自己拉扯了。按住一个键，让轮盘替你决定。

**Eatoday** 把 FoloToy AI Passport 变成一台口袋里的“今天吃哪家”轮盘。内置 30 家馆子，
首次开机还会给你备好一份“常吃”列表；自己的列表可以直接用手机改写，不用装任何东西。

**版本：v1.1** —— 手机端列表编辑器、中文运行时字体，机器上不再需要选词输入。

## 怎么玩

| 场景 | 手势 | 结果 |
| --- | --- | --- |
| 主界面 | 长按 `上` | 从随机一项开始转；松手减速停住 |
| 主界面 | 短按 `下` | 手动切到下一个 |
| 主界面 | 长按 `下` | 切换轮盘：默认池 → 我的1 … 我的3 → 默认池（空列表自动跳过） |
| 主界面 | 短按 `确定` | 认下眼前这个结果 |
| 主界面 | 长按 `确定` | 打开手机编辑器（开启 WiFi 热点） |
| 旋转中 | 松开 `上` | 开始减速 |
| 旋转中 | 短按 `下` | 立刻停在当前项 |
| 手机编辑器页 | 长按 `下` | 关闭热点并返回 |

还没开始转的时候，中央卡片显示标题和“按住 ↑ 开始转”，不会停在某一家店；切换列表也不会打断它。
开始转之后，每次起转都从随机一项出发，避免老是同一家。

## 用手机编辑列表

1. 主界面长按 `确定`，设备显示热点名（如 `Eatoday-3F2A`）、密码 `eatoday88`、地址
   `http://192.168.4.1`。
2. 手机连上这个热点（不需要互联网；手机提示“此网络无互联网”时保持连接即可）。
3. 浏览器打开 `http://192.168.4.1`，有 3 套互相独立的列表：改套名、增删条目（每套最多 50 项）、
   选好轮盘用哪一套，点 **保存到设备**。
4. 页面底部有「回到封面」按钮：一点设备就退回待机画面并关掉热点；也可以直接在设备上长按 `下` 退出，界面会停在你上次看到的那一项，不会闪屏。

手机输入的字用运行时字体渲染，覆盖 GB2312 全集，生僻字不会变成方框。

## 里面有什么

- **30 项默认池**：京菜烤鸭、小吃快餐、火锅、川味、家常、亲民小馆，再加一组兜底选择。
- **一份现成的「常吃」列表**：首次开机写入第 1 套，18 家日常店，开机就能转；随时可改可清空。
- **3 套自己的列表**，每套最多 50 项，与默认池互相独立；空列表不会出现在设备上。
- **数据都在设备里**：默认池和自己的列表都存在 NVS，断电不丢。热点只在编辑器页打开期间存在，
  不会向外部发送任何内容。

## 编译与刷写

需要 ESP-IDF 5.5.3（esp32c3）。合并镜像可直接写到 `0x0`：

```bash
./tools/validate.sh            # 仓库检查 + 主机测试 + 固件构建
python -m esptool --chip esp32c3 -p <PORT> write_flash 0x0 build/FoloToy-AI-Passport-full.bin
```

主机测试覆盖停止后的索引计算与随机起点、列表存储与空列表跳过、按键路由状态机、字体逐字覆盖。
