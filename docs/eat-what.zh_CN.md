# Eatoday：今天吃什么

给 FoloToy AI Passport 做的离线决策小玩具：转盘里是北京常见馆子和品类，用三个实体按键转。
不联网、不开蓝牙、不放音频，也没有任何付费依赖；数据只落在 NVS。

这个应用把基线的硬件测试菜单换成了自己的两屏界面。

## 交互契约

| 场景 | 手势 | 结果 |
| --- | --- | --- |
| 主界面静止 | 上键长按 | 开始旋转；松开后减速停止 |
| 主界面静止 | 下键短按 | 手动下一个 |
| 主界面静止 | 下键长按 | 切换轮盘范围：全部 / 仅种子池 |
| 主界面静止 | 确定短按 | 接受当前结果（显示“就它了”） |
| 主界面静止 | 确定长按 | 进入添加页 |
| 主界面旋转 | 上键松开 | 触发减速 |
| 主界面旋转 | 下键短按 | 立即停止 |
| 添加页 | 上/下短按 | 移动候选词光标 |
| 添加页 | 确定短按 | 选中当前词为品类，可再选一个词作为追加短名称 |
| 添加页 | 确定长按 | 保存（没追加时只存品类标签） |
| 添加页 | 上键长按 | 取消并返回 |

三个按键共用一个 ADC 分压，所有手势统一由 App Router（`main/eat_what_router.c`）分发，
页面本身不读按键。

## 界面

- 主界面：深色底 `#0B0F14`；顶部标题“北京 · 今天吃什么”，右上角电量；中央一张圆角卡片，
  按字符数用 44/32/24 px 显示当前选项；下方“种子池 N · 我的 M”；再下一行是轮盘范围；
  底部两行按键提示。用户条目加 ★ 前缀。
- 添加页：顶部“今天吃了什么？”，中间显示已输入文字（最多 6 字），底部 3 行候选词并跟随光标滚动。

两屏都用普通 LVGL 控件重新绘制，没有复用基线的测试菜单、`ui_pixel_*` 外壳或任何 demo 页面。

## 数据

- 种子池 30 项，覆盖京菜烤鸭、小吃快餐、火锅、川味、家常、亲民小馆与轻决策兜底
  （`main/eat_what_seed.c`）。
- 首次启动把种子快照写入 NVS（命名空间 `eatwhat`，键 `seed`，另有 `seed_ver`）；
  之后从快照读取，快照缺失或损坏时回退到编译期表。
- 用户池：键 `user`，最多 32 条、每条最多 31 字节 UTF-8，池内同名拒绝追加；轮盘范围键 `scope`。
- blob 布局（小端）：`u16 version | u16 count | count × char[32]`。
- 添加页没有键盘输入，只提供 12 个高频词。选中一个就只存该词；再短按确定会追加第二个词，
  形成“品类·短名称”。

## 轮盘时序

位置用整数 milli-index 表示，速度是 milli-index/ms，因此同一组 `dt` 序列总是停在同一条。
起转速度 22 项/秒；减速时间常数 260 ms，低于 0.9 项/秒时吸附到最近条目。

## 字体

中文使用五档 LVGL 子集（16/20/24/32/44 px），源字体为 Noto Sans SC（OFL 1.1）。
`tools/gen_eat_what_fonts.sh` 依据 `main/eat_what_text.h`、`main/eat_what_text.c`
与 `main/eat_what_seed.c` 里的字符串字面量重新生成；
`tests/test_eat_what_font_coverage.py` 在出现缺字时失败。
许可证与重生成步骤见 `assets/fonts/README.zh_CN.md`。

## 测试

主机测试不需要硬件：

```bash
./tools/validate.sh --static
```

覆盖内容：停止后的索引计算与减速确定性、用户池追加与 blob 往返、App Router 在静止/旋转中/添加页
三条分支、种子数据完整性，以及字体逐字覆盖。
