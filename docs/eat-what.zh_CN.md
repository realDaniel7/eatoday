# Eatoday：今天吃什么

给 FoloToy AI Passport 做的离线决策小玩具：转盘里是馆子，你自己的列表可以在手机上编辑。
三个实体按键负责转。不联外网、不放音频、没有付费依赖；数据只落在 NVS。

这个应用把基线的硬件测试菜单换成了自己的两屏界面。

## 交互契约

| 场景 | 手势 | 结果 |
| --- | --- | --- |
| 主界面静止 | 上键长按 | 从随机一项起转；松开后减速停止 |
| 主界面静止 | 下键短按 | 手动下一个 |
| 主界面静止 | 下键长按 | 循环轮盘：默认池 → 我的1 … 我的3 → 默认池，空列表跳过 |
| 主界面静止 | 确定短按 | 接受当前结果 |
| 主界面静止 | 确定长按 | 打开手机编辑器（SoftAP + HTTP） |
| 主界面旋转 | 上键松开 | 触发减速 |
| 主界面旋转 | 下键短按 | 立即停止 |
| 编辑器页 | 下键长按 | 关闭热点并返回（界面停在离开前的状态） |
| 手机页面 | 「回到封面」 | 设备退回待机画面并关闭热点 |

机器上不再做选词输入，列表都在手机上编辑。第一次转之前中央卡片显示标题和“按住 ↑ 开始转”，
切换列表不会离开这个状态——待机画面不会停在某一家店。

## 界面

- 主界面：深色底 `#0B0F14`；顶部标题与右上角电量；中央圆角卡片（待机提示，或当前选项：
  自定义条目用运行时字体 40/28px）；统计行“默认 N · 列表名 M”；范围行显示当前列表；
  底部两行按键提示。
- 编辑器页：热点名、密码、访问地址与提示；停留到长按下键退出。

两屏都用普通 LVGL 控件重新绘制，没有复用基线的测试菜单或 `ui_pixel_*` 外壳。

## 手机编辑器

`main/eat_wifi.c` 启动 WPA2 SoftAP（名为 `Eatoday-XXXX`，取 MAC 末两字节），密码
`eatoday88`；`main/eat_web.c` 提供：

| 路由 | 作用 |
| --- | --- |
| `GET /` | 手机单页（改名、增删条目、选当前列表、保存） |
| `GET /api/state` | 当前列表与当前索引的 JSON |
| `POST /api/save` | 整体替换；校验后写 NVS 并刷新轮盘 |

设备侧限制：3 套、每套 50 项、单个条目 10 字符、套名 7 字符、同套去重、请求体 ≤ 8KB。
WiFi 只在编辑器页打开期间启用。

## 数据

- 默认池 30 项（`main/eat_what_seed.c`），首次启动写入 NVS（含 `seed_ver`）；快照缺失或
  损坏时回退到编译期表。
- 出厂列表：首次启动（NVS 里没有列表信息）时给第 1 套填入 18 家常去的店，套名「常吃」
  （`eat_sets_fill_defaults`）。清空后不会再被填回；只要元信息存在就不再套用出厂内容。
- 列表：`set_meta`（套名与当前索引）加 `set0`…`set2`（每套一个 blob，最多 50 × 32 字节）。
  列表与默认池互相独立；空列表在切换时被跳过，轮盘不会空转。
- 迁移：v0.1 的扁平 `user` 列表在新格式首次启动时导入第 1 套。

## 轮盘时序与随机

位置用整数 milli-index 表示，速度是 milli-index/ms，因此同一组 `dt` 序列总是停在同一条。
起转速度 22 项/秒；减速时间常数 260 ms，低于 0.9 项/秒时吸附到最近条目。
`eat_wheel_randomize()` 用调用方给的随机值决定起始项：开机落点与每次起转都随机，
避免老是同一家赢。

## 字体

两层：

1. 位图子集（16/20/24/32/44 px）用于固定文案与默认池店名，按 `main/eat_what_text.h`、
   `main/eat_what_text.c` 与 `main/eat_what_seed.c` 的字面量生成；16px 一档带运行时
   fallback，漏掉的字会退到 TTF，而不是显示方框。
2. 运行时 TTF（`assets/fonts/noto-sc-gb2312.ttf`，GB2312 全集 6763 字）以只读数据嵌入固件，
   由 LVGL 的 Tiny TTF 栅格化，作为 fallback 以及手机输入条目的主字体。若用位图覆盖同样
   范围，24px 一档就要约 6.5MB，放不进 8MB Flash。

两份字体都源自 Noto Sans SC（SIL Open Font License 1.1），见 `assets/fonts/README.md`。

## 测试

```bash
./tools/validate.sh --static
```

覆盖：停止后的索引计算与随机起点、列表存储、meta 往返、出厂默认、空列表跳过、
App Router 在静止/旋转/编辑器页三条分支、种子数据完整性，以及字体逐字覆盖。

## 设备上未自动验证的部分

热点与 HTTP 往返需要人工验证：打开编辑器、手机接入、保存列表。自动化测试覆盖数据模型与
按键路由，不覆盖射频与真实浏览器交互。
